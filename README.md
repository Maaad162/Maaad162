## 01 — Sobre mim

Gosto da ideia de que um bom software deve tornar o trabalho mais claro, não mais complicado.

Meus projetos exploram justamente isso: transformar informações, etapas e processos em ferramentas que possam ser utilizadas no dia a dia.

Tenho desenvolvido aplicações web voltadas à **organização de atividades, acompanhamento operacional e visualização de informações**, especialmente no contexto da construção civil.

Atualmente, meus repositórios incluem projetos com React, TypeScript, Firebase e JavaScript.

> **Menos informação perdida. Mais clareza sobre o próximo passo.**

CONFIGURAÇÃO DA ANIMAÇÃO SNAKE
============================================================

Esta etapa é necessária apenas uma vez.

1. Crie o repositório público:

----------------- INÍCIO DO YAML -----------------

name: Snake Contributions

on:
  schedule:
    - cron: "15 3 * * *"
  workflow_dispatch:

permissions:
  contents: write

jobs:
  generate:
    runs-on: ubuntu-latest

    steps:
      - name: Gerar Snake SVG
        uses: Platane/snk/svg-only@v3
        with:
          github_user_name: Maaad162
          outputs: |
            dist/github-contribution-grid-snake.svg?color_snake=#4169E1&color_dots=#0D1117,#17213B,#243B7A,#3454B4,#4169E1

      - name: Publicar SVG
        uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

------------------ FIM DO YAML ------------------

4. Faça commit do snake.yml na branch padrão.

5. Acesse a aba Actions do repositório.

6. Selecione Snake Contributions.

7. Clique em Run workflow.

8. Verifique se a execução terminou corretamente e criou
   a branch output com o arquivo SVG.

9. Depois disso, a animação poderá aparecer neste README.
